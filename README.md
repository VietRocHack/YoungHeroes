# Young Heroes

An emergency-preparedness training app for kids aged 4-12: a simulated 911
voice call with an AI dispatcher, plus two skill-building mini-games. Built
during a VietRocHack hackathon, now permanently deployed on the team's own
infrastructure.

Live at [youngheroes.vietrochack.com](https://youngheroes.vietrochack.com).

See [`CLAUDE.md`](CLAUDE.md) for the repo map and local dev commands, and
[`docs/`](docs/) for architecture decisions, the original pitch, and the
deploy runbook.
