# docs

- `adr/` — architecture decision records, one file per real decision, numbered
  in order. Read these before making an architectural change.
- `product/pitch.md` — the original Devpost pitch, so "why does this exist"
  survives independent of whoever built it.
- `progress/YYYYMMDD.md` — one file per calendar day, append-only within a day.
- `runbook.md` — one-time GCP/Firebase setup checklist, plus ongoing operational notes.
- `backlog.md` — known non-blocking issues and cleanup, checked off as they land.
